# ordinal_regression_STorder
Code and data for 
**"A General Class of Ordinal Regression Models Developed Based on the Notion of Usual Stochastic Order"**

The focus of this repository is the real ordinal data sets analysis in Section 5.

---

## Repository contents

- `data`
   data files and descriptions of data sources.

- `R`
   R Markdown files and common R functions used to reproduce the empirical analyses.

- `wscc1996_analysis.Rmd`  
  R Markdown file containing all code for the WSCC 1996 data analysis and simulations.
