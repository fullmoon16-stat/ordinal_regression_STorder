# Code files

This folder contains the R code used to reproduce the empirical analyses reported in Section 5 of the manuscript.

All scripts should be run from the root directory of this repository.

## Common functions

- `common_functions.R`

  This file contains common functions used in the proposed ordinal regression models, including baseline survival functions, transformation functions, likelihood evaluation, model fitting, data-driven initial values, and model-selection utilities.

## Empirical analysis scripts

- `5_1_mental_health.Rmd`

  This file reproduces the mental health data analysis in Section 5.1. The corresponding results are reported in Tables 5-7 and Figure 4.

- `5_2_retinopathy.Rmd`

  This file reproduces the retinopathy data analysis in Section 5.2. The corresponding results are reported in Tables 8-11.

- `5_3_pm25.Rmd`

  This file reproduces the fine particulate matter level data analysis in Section 5.3. The corresponding results are reported in Tables 12-14.
