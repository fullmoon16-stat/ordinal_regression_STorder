# Data sources

This file describes the three data sets used in the empirical analyses in the manuscript and supplementary material. It provides the data sources, loading instructions, variable definitions, coding schemes, and preprocessing steps used in the analyses. Data for the simulation studies are generated by the corresponding scripts and are therefore not included as separate data files.


## Adolescent Placement Study (APS) data

The APS data are loaded directly from the R package `aplore3` by using:

```r
library(aplore3)
data("aps")
```

The data set contains `n = 508` psychiatrically hospitalized adolescents. The response variable is:

* `danger`: danger to others, measured on a four-point ordinal scale and coded as 1 = Unlikely, 2 = Possible, 3 = Probable, and 4 = Likely.

The covariates used in the manuscript are:

* `weeks`: length of hospitalization in weeks, obtained by dividing los, originally measured in days, by 7.
* `behav`: behavioral symptoms score, ranging from 0 to 9.
* `gender`: gender indicator, coded as 0 = female and 1 = male.
* `custd`: state custody status, coded as 0 = no and 1 = yes.

## Retinopathy data

The retinopathy data are loaded directly from the R package `catdata` by using:

```r
library(catdata)
data("retinopathy")
```

The data set contains `n = 613` observations on persons with retinopathy-related information. The response variable is an ordered disease-severity variable:

* `RET`: ordinal response variable, coded as 0 = no retinopathy, 1 = nonproliferative retinopathy, and 2 = advanced/proliferative retinopathy or blindness. For fitting the proposed models, `RET` is internally recoded to consecutive categories 1, 2, and 3.

The covariates used in the manuscript are:

* `DIAB`: diabetes duration in years.
* `GH`: glycosylated hemoglobin, measured in percent.
* `BP`: diastolic blood pressure, measured in mmHg.
* `SM`: smoking status, coded as 1 = smoker and 0 = non-smoker.

The continuous covariates `DIAB`, `GH`, and `BP` were standardized using the `scale()` function in R before model fitting.


## White wine quality data

The white wine quality data were obtained from the Wine Quality data set in the UCI Machine Learning Repository. The original UCI file is `winequality-white.csv`. The data used in the analyses are provided as `data/wine_white_processed.csv`; this file retains the original 11 covariates and `quality` variable and additionally includes `y_order`, which reindexes the observed quality levels from 3, ..., 9 to 1, ..., 7.

The data are loaded in Python by using:

```Python
import pandas as pd 
wine = pd.read_csv("data/processed/wine_white_processed.csv")
```

The data set contains `n = 4898` white wine samples. The response variable is:

* `quality`: sensory quality score. The observed values range from 3 to 9, giving seven ordered response categories.

* `y_order`: recoded ordinal response, with the original quality levels 3, ..., 9 mapped to 1, ..., 7, respectively.

The 11 continuous physicochemical covariates used in the supplementary analysis are:

* `fixed_acidity`: fixed acidity.
* `volatile_acidity`: volatile acidity.
* `citric_acid`: citric acid.
* `residual_sugar`: residual sugar.
* `chlorides`: chloride concentration.
* `free_sulfur_dioxide`: free sulfur dioxide concentration.
* `total_sulfur_dioxide`: total sulfur dioxide concentration.
* `density`: density.
* `ph`: pH.
* `sulphates`: sulphate concentration.
* `alcohol`: alcohol content.

For the additional five-category analysis, quality 3 is treated as 4 and quality 9 as 8, resulting in the five ordered categories 4, ..., 8, which are then reindexed as 1, ..., 5. This recoding is performed by the analysis code, so a separate five-category data file is not required.

The covariates stored in the data file are not pre-standardized. Within each cross-validation split, the means and standard deviations are computed using the relevant training data and then applied to the validation or test data.
